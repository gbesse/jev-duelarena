# Bracket semantics

The entrant list is padded to the next power of two. A `null` slot is a labeled bye and advances its opponent without a Jev call. Matches within a round run concurrently; the callback and SSE-capable consumers receive them in actual completion order. A per-criterion tie becomes an overall weighted tie only when the code-owned totals match. Brackets advance the first entrant on an overall tie and record that deterministic policy explicitly.
